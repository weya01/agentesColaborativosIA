```
Turno 0: 2 agentes, 50% bombas
Turno 1: 3 agentes, 53.75% bombas
...
Turno 8: 10 agentes, 80% bombas

Fórmula: bombas = 50 + (30 * (agentes - 2) / 8)
```

- Seleção múltipla de abordagens
- Ctrl+Click para múltipla seleção
- Abordagens: A, B, C
